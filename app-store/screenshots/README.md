# App Store screenshots

These screenshots were generated by `AppUITests.testCaptureAppStoreScreenshots`
and `AppUITests.testCaptureExpandedAppStoreScreenshots` with a debug-only
fixture. The fixture uses familiar example medication names and relative sample
dates so the listing is relatable without exposing anyone's personal data. It
is compiled out of Release builds, and the examples are not dosing guidance or
recommendations.

## Upload order

Use the same order for each device class:

1. `01-home.png` — medication overview and ready/waiting states
2. `02-actions.png` — native action dialog over the blurred list
3. `03-history.png` — chronological dose history, opened at the latest record
4. `04-add-medication.png` — creating a medication and entering personal limits
5. `05-notifications.png` — optional ready notifications with an example
6. `06-privacy.png` — on-device data model, color explanation, and disclaimer
7. `07-backup-share.png` — portable JSON backup in the native share sheet

## Verified output

- `iphone-6.9`: 1320×2868 pixels, RGB, no alpha channel
- `ipad-13`: 2064×2752 pixels, RGB, no alpha channel

Do not replace these with captures containing a real person's medication names or dose history.

# App Store screenshots

These screenshots were generated by `AppUITests.testCaptureAppStoreScreenshots` with a debug-only fixture. The fixture uses generic medication names and relative sample dates; it is compiled out of Release builds.

## Upload order

Use the same order for each device class:

1. `01-home.png` — medication overview and ready/waiting states
2. `02-actions.png` — native action dialog over the blurred list
3. `03-history.png` — chronological dose history, opened at the latest record

## Verified output

- `iphone-6.9`: 1320×2868 pixels, RGB, no alpha channel
- `ipad-13`: 2064×2752 pixels, RGB, no alpha channel

Do not replace these with captures containing a real person's medication names or dose history.
